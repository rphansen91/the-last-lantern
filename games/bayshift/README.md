# Bayshift

A mobile-first sliding freight puzzle for Night Arcade. Slide glowing crates into matching bay doors before the night shift ends.

Zero dependencies. Portrait-first touch: swipe a crate to slide it until it hits a wall, another crate, or a matching door. Wrong-color doors block. Undo / Reset on the thumb dock. Ten handcrafted bays.

Open with `?from=arcade` for a **← Library** chip back to the arcade root.

```
index.html             the whole game
manifest.webmanifest   PWA
sw.js                  offline cache (bump VERSION on ship)
icons/                 procedural amber dock icons
screenshots/cover.png  catalog cover
```
