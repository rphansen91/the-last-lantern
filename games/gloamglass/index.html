How to pour

Night-ink sort

  • Tap a phial to lift it, tap another to pour. Tap the same again to set it down.
  • Pour only onto an empty phial or one whose top color matches, with room left.
  • The whole matching top run pours (as much as fits). Leftover stays behind.
  • Clear a loft when every phial is empty or filled with a single hue.
  • Undo steps back a pour. Shuffle rearranges the phials. Extra adds one empty glass once per loft.
